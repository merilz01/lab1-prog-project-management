# lab1-prog-project-management
Лабораторная работа №1: ООП, исключения, XML/JSON

## Описание

Программа моделирует систему управления проектами: пользователи
(менеджеры и разработчики), команды, проекты, спринты, задачи
(баги и фичи), комментарии, теги и учёт времени.

## Структура проекта

- `exceptions.py` - иерархия собственных исключений
- `models.py` - 14 классов предметной области
- `main.py` - сервис CRUD, работа с JSON и XML
- `data/` - файлы данных (JSON и XML)

## Как запустить

```bash
python main.py
